# App Review Sentiment Analysis

Multi-model sentiment classifier trained on ~49,000 app reviews. Classifies reviews as **Negative**, **Neutral**, or **Positive** using five different machine learning approaches.

---

## Models & Results

| Model | Accuracy |
|---|---|
| Naive Bayes | 68.3% |
| Support Vector Machine | 65.9% |
| Random Forest | 63.8% |
| Logistic Regression | 58.1% |
| LSTM | 52.4% |

---

## Dataset

- 49,612 app reviews
- 3 classes: Positive (26,000), Negative (15,455), Neutral (8,157)
- Class imbalance handled using `class_weight='balanced'`

---

## Approach

**TF-IDF Models** (Naive Bayes, SVM, Random Forest, Logistic Regression)
- Text cleaned: lowercased, non-alphabetic characters removed
- TF-IDF vectorization with 20,000 max features, fit on training data only to prevent data leakage
- Vectorizer saved to `tfidf_vectorizer.pkl` for inference

**LSTM**
- Keras Tokenizer with vocab size 10,000 and OOV token
- Embedding layer (128 dims) → LSTM (64 units) → Dropout (0.3) → Dense (softmax)
- Early stopping on validation loss with patience of 2
- Tokenizer saved to `lstm_tokenizer.pkl`

## How to Run

1. Upload the dataset to Google Drive
2. Open `sentiment-analysis(1).ipynb` in Google Colab
3. Update the dataset path in Cell 5 to match your Drive location
4. Runtime → Run all

Trained model files (`.pkl`, `.keras`) are not included in this repo — they are generated by running the notebook.
